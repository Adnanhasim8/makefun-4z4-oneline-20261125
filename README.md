# One Line, One Laugh

Entry for the make.fun competition `u-4z4ghtbwm1fn7mibrqum4bxgfghhgqzriyhd8v3-one-line-0be61e5a`: a program that writes a single funny line to `/output/entry.txt`.

The line: "The library fined me for returning a book I never borrowed — overdue since 1847."

## How to run

```sh
python3 main.py
```

This writes the one-liner to `/output/entry.txt` (UTF-8, a single line of at most 140 characters). Python 3.13 standard library only; no network at run time.
